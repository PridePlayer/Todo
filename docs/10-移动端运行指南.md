# 10 · 移动端（Android）运行指南

> 现状：App 骨架已完成，可在真机上跑通登录、今日待办、四象限、打卡、设置。
> 尚未完成的是"本地提醒"与"后台常驻"，见文末。

---

## 1. 为什么是 Expo Go，而不是直接装 APK

`npx expo run:android` 需要本地 Android SDK + JDK 才能编译。这台开发机上两个都没有，
所以第一轮用 **Expo Go**（一个通用容器 App）直接加载 JS，不需要任何构建。

代价要说清楚：

| 能力 | Expo Go | 正式 APK |
|---|---|---|
| 界面、接口、本地 SQLite | 可用 | 可用 |
| 本地定时提醒 | **不可用**（SDK 53+ 在 Expo Go 里移除了通知能力） | 可用 |
| 桌面图标 / 独立安装 | 无（要从 Expo Go 里进） | 有 |

所以 Expo Go 只用来验证"界面与数据对不对"。提醒功能要等 APK。

## 2. 手机端准备

1. 手机连上和电脑**同一个 WiFi**（电脑的 WLAN 地址是 `10.141.3.124`）
2. 装 Expo Go：
   - 官网直下 APK：<https://expo.dev/go?sdkVersion=58&platform=android&device=true>
   - 或 Google Play 搜 "Expo Go"
   - **必须是支持 SDK 58 的版本**，旧版会提示 "project is incompatible"

## 3. 启动 Metro

只启一个进程 —— App 默认连生产服务器 `https://todo.stellamp.me`，不需要本地后端。

**PowerShell**

```powershell
cd E:\11_WorkBuddyFiles\Todo\apps\mobile
$env:REACT_NATIVE_PACKAGER_HOSTNAME="10.141.3.124"
npx expo start --lan
```

**CMD**

```bat
cd /d E:\11_WorkBuddyFiles\Todo\apps\mobile
set REACT_NATIVE_PACKAGER_HOSTNAME=10.141.3.124
npx expo start --lan
```

> `REACT_NATIVE_PACKAGER_HOSTNAME` 不能省。这台机器上有一个 VPN 虚拟网卡
> （`198.18.0.1`），Expo 自动选地址时可能选到它，于是二维码里的 IP 手机根本连不到，
> 表现是"扫码后一直转圈"。

终端里会出现二维码。用 Expo Go 扫，或选 "Enter URL manually" 输入
`exp://10.141.3.124:8081`。

首次加载要打包 2.8MB 的 Hermes 字节码，大约 30–60 秒，之后是秒开。

## 5. 连不上时按这个顺序查

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫码后一直转圈 | Metro 的 IP 不对 | 确认用了 `REACT_NATIVE_PACKAGER_HOSTNAME`，且二维码里是 `10.141.3.124` |
| 同上，IP 也对 | Windows 防火墙拦了 8081 | 首次运行时会弹"是否允许 Node.js 访问网络"，勾**专用网络**；没弹就去「Windows 安全中心 → 防火墙 → 允许应用通过」里放行 Node.js |
| 提示 "project is incompatible" | Expo Go 版本低于 SDK 58 | 卸载重装最新版 |
| 能进界面但登录报"连不上服务器" | 手机访问不到 `todo.stellamp.me` | 浏览器试一下该地址；打不开就是手机网络问题，与 App 无关 |
| 登录报"邮箱或密码不正确" | 账号不对 | 见第 4 节 |
| 改代码后界面没变 | Fast Refresh 断了 | 终端里按 `r` 重载，或摇一摇手机选 Reload |

| 页签 | 内容 |
