# 04 · UI 设计规范（瑞士国际主义）

| 项 | 内容 |
|---|---|
| 文档版本 | v1.0（第二批交付） |
| 风格 | 瑞士国际主义 / International Typographic Style |
| 唯一彩色 | 克莱因蓝 `#002FA7` |
| 主题 | 仅浅色（深色模式 P1，本规范不含） |
| 落地文件 | `apps/web/src/design/tokens.css`、`apps/mobile/src/design/tokens.ts` |

> 这不是灵感板。下面每一条都要能回答"多少 px、哪个变量、什么情况例外"。任何"看着来"的数值都属于缺陷。

---

## 1. 视觉基调（五条，按仲裁优先级排序）

1. **网格先于装饰。** 所有元素的尺寸与位置必须落在 8pt 基线上。当审美与网格冲突时，改审美。
2. **只有一个彩色。** 克莱因蓝 `#002FA7`。其余全部灰阶。当你想用第二种颜色表达状态时，改用位置、字重、图形或文字。
3. **层级靠字重与留白，不靠阴影与圆角。** 全站零 `box-shadow`、零渐变。
4. **直角优先。** 圆角 2px，唯一例外是 chip（999px pill，因为要和小方块按钮区分）。
5. **无装饰性图形。** 不用插画、不用 emoji 做图标、不用背景纹理。空状态也用排版解决。

### 1.1 瑞士风格的三条具体约束（防止"看起来像"但骨子里不是）

- **左对齐，绝不居中。** 除登录页标题与空状态外，一律左对齐。居中是瑞士风格的敌人。
- **字号跳跃要大。** 页面标题 28px 与正文 14px 之间不允许出现 18px 这种"温吞"的中间档。
- **线的数量要少但要满宽。** 分隔线必须从左边缘贯穿到右边缘（或整栏），不允许"半截线"。

## 2. 色彩系统

### 2.1 中性阶（12 级）

| Token | Hex | 用途 |
|---|---|---|
| `--n-0` | `#FFFFFF` | 页面底色、卡片底 |
| `--n-50` | `#FAFAFA` | 次级面板底（侧栏、抽屉底） |
| `--n-100` | `#F4F4F5` | hover 底、骨架屏底 |
| `--n-200` | `#E4E4E7` | **描边线、网格线**（全站最高频的线） |
| `--n-300` | `#D4D4D8` | 禁用描边、输入框底边 |
| `--n-400` | `#A1A1AA` | 占位文字、禁用文字 |
| `--n-500` | `#71717A` | 次要文字（时间戳、辅助说明） |
| `--n-600` | `#52525B` | 正文次要段 |
| `--n-700` | `#3F3F46` | 正文（默认文字色） |
| `--n-800` | `#27272A` | 强调正文、列表标题 |
| `--n-900` | `#18181B` | 标题 |
| `--n-1000` | `#0A0A0A` | 极大标题、Logo |

### 2.2 强调色（5 档）

| Token | 值 | 用途 |
|---|---|---|
| `--a-100` | `#EDF1FA` | 选中行底色、拖拽落点底色 |
| `--a-200` | `#C8D3EE` | 待办块描边（弱态） |
| `--a-500` | `#002FA7` | **主按钮、今天列头、焦点环、选中药丸** |
| `--a-600` | `#00227A` | 主按钮 hover |
| `--a-700` | `#001A5C` | 主按钮 active |

**允许使用 `--a-500` 的完整清单（只有这 7 处）**：
① 主按钮底色 ② 今天列头文字与 2px 下划线 ③ 焦点环 ④ 当前选中的导航项 ⑤ 热力图最高档 ⑥ 进度条填充 ⑦ 待办时间块的 2px 描边。

**禁止清单**：正文文字、普通链接以外的装饰、图表多色、标签彩色、错误态（错误用红）、成功态（不需要绿）。

### 2.3 语义色（只有两个）

| Token | Hex | 用途 |
|---|---|---|
| `--danger` | `#C0311E` | 逾期日期文字、删除按钮文字、危险描边 |
| `--warn` | `#A16207` | 同步异常黄线的文字部分、离线提示 |

> 没有 `--success`。成功不需要颜色，用"消失"和"形态变化"表达（复选框打勾即成功）。

### 2.4 对比度矩阵（WCAG AA，正文 ≥4.5:1）

| 文字色 \ 底色 | `--n-0` | `--n-50` | `--n-100` | `--a-100` |
|---|---|---|---|---|
| `--n-700`（正文） | 9.7:1 ✅ | 9.2:1 ✅ | 8.6:1 ✅ | 8.1:1 ✅ |
| `--n-800`（强调） | 13.2:1 ✅ | 12.6:1 ✅ | 11.8:1 ✅ | 11.1:1 ✅ |
| `--n-500`（次要） | 4.6:1 ✅ | 4.4:1 ⚠️ | 4.1:1 ❌ | 3.9:1 ❌ |
| `--n-400`（占位） | 2.6:1 ❌ | — | — | — |

**执行规则**：`--n-500` 只允许出现在 `--n-0` 上；在 `--n-50` 及以上底色，次要文字必须升到 `--n-600`。占位文字允许低于 AA（WCAG 明确豁免），但不得低于 2.5:1。

白字在 `--a-500` 上：**8.6:1** ✅（主按钮安全）。

## 3. 字体系统

### 3.1 字族

```css
--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
             "Source Han Sans SC", "Noto Sans CJK SC", sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
```

- **Inter 自托管**（`woff2`，仅 400 / 500 / 600 三个字重，拉丁子集约 32KB）。不引 CDN（离线不可用、隐私）。
- 中文一律走系统栈。**不引入思源黑体 Web 字体**（CJK 字体 3~8MB，与"首屏 <1.5s"目标冲突）。
- **所有数字加 `font-variant-numeric: tabular-nums`**。日历列、统计、计时器必需，否则数字宽度跳动会让表格抖。

### 3.2 字号阶梯（7 级，不允许出现第 8 级）

| Token | 字号 / 行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `--t-xs` | 11 / 16 | 500 | `+0.08em` 全大写 | 分类标签、象限角标、星期缩写 |
| `--t-sm` | 12 / 18 | 400 | `0` | 辅助信息、时间戳、热力图月份 |
| `--t-base` | 13 / 20 | 400 | `0` | 列表次要行、表单提示 |
| `--t-body` | 14 / 22 | 400 | `0` | **正文默认**、列表标题、按钮 |
| `--t-md` | 16 / 24 | 500 | `-0.01em` | 卡片标题、抽屉标题 |
| `--t-lg` | 20 / 28 | 600 | `-0.02em` | 区块标题（"待安排"、"今天"） |
| `--t-xl` | 28 / 36 | 600 | `-0.02em` | 页面标题（"四象限"、"打卡"） |
| `--t-2xl` | 40 / 48 | 600 | `-0.03em` | 登录页标题、统计大数字 |

> 移动端整体降一档：`--t-xl` 在手机上用 24/32，`--t-2xl` 用 32/40。字号阶梯本身不变。

### 3.3 排版规则

- 段落最大宽度 **68ch**（约 596px @14px）。超过就打不住。
- 中英混排：数字与英文两侧**不加空格**（与中文紧排），但 `14:30` 这类时间前后各留 1 个半角空格。
- 标题不使用 `text-transform` 以外的大小写变换；`--t-xs` 是唯一允许 `uppercase` 的层级。
- 截断：单行 `text-overflow: ellipsis`；多行用 `-webkit-line-clamp`（列表行 2 行，事件块 3 行）。

## 4. 网格与间距

### 4.1 基线

8pt 基线。**所有纵向尺寸（高度、内边距、margin）必须是 4 的倍数**，其中 4 只用于紧凑内联间距（如图标与文字之间）。

间距刻度（只用这 8 个值）：

```
--sp-1: 4px    --sp-2: 8px    --sp-3: 12px   --sp-4: 16px
--sp-6: 24px   --sp-8: 32px   --sp-12: 48px  --sp-16: 64px
```

> 不设 `--sp-5 / --sp-7`。缺档能逼出更清晰的分组，也避免"16 还是 20"的无意义纠结。

### 4.2 响应式栏网格

| 断点 | 栏数 | Gutter | 外边距 | 主内容最大宽 |
|---|---|---|---|---|
| ≥1440（桌面宽） | 12 | 24 | 40 | 1440 |
| 1024–1439（桌面窄） | 12 | 20 | 32 | 1280 |
| 768–1023（平板） | 8 | 20 | 24 | — |
| <768（手机） | 4 | 16 | 16 | — |

### 4.3 应用骨架的固定尺寸（写死，不许自由发挥）

| 元素 | 尺寸 |
|---|---|
| 左侧图标导航 | 宽 **64px**，图标 24px，上下内边距 16px，项间距 4px |
| 右侧详情抽屉 | 宽 **380px**，从右滑入 |
| 主区内「待安排」侧栏 | 宽 **280px** |
| 顶部工具栏 | 高 **52px**（含 1px 下边线） |
| 列表行高 | **48px**（单行）/ 64px（双行） |
| 底部 Tab（移动端） | 高 **56px** + 安全区内边距 |
| 移动端顶栏 | 高 **48px** |

### 4.4 时间网格（日历的核心度量）

| 项 | 值 |
|---|---|
| 1 小时高度 | **56px** |
| 15 分钟 | 14px（最小可点高度） |
| 小时分隔线 | 1px `--n-200` |
| 半小时分隔线 | 1px `--n-100`（更淡，可关） |
| 当前时间线 | 2px `--a-500`，左端 6px 圆点 |
| 事件块最小高度 | 22px（不足时显示细条，hover 出 tooltip） |
| 事件块内边距 | 4px 8px（高度 <28px 时改为 2px 8px） |
| 重叠列间隙 | 2px |

## 5. 边框、圆角与层次

| 项 | 值 |
|---|---|
| 默认描边 | `1px solid var(--n-200)` |
| 强调描边 | `2px solid var(--a-500)` |
| 输入框 | 1px `--n-300`，聚焦时 2px `--a-500` |
| 圆角 | 按钮/卡片/输入框/事件块 = **2px**；chip = **999px**；复选框 = **2px** |
| 禁止 | `border-radius > 8px`（chip 除外）、`box-shadow`、`background: linear-gradient`、`backdrop-filter` |

层级（用 z-index，不用阴影造层次）：

| 层 | z-index |
|---|---|
| 基础内容 | 0 |
| 粘性表头 / 今天列头 | 10 |
| 拖拽中的元素 | 30 |
| 抽屉 | 40 |
| 弹层 / 下拉 / 快速新增 | 50 |
| Toast | 60 |

**唯一的半透明**：抽屉打开时的遮罩 `rgba(10,10,10,0.24)`。

## 6. 组件规范

### 6.1 按钮

| 型 | 底 | 字 | 描边 | 用途 |
|---|---|---|---|---|
| 主 | `--a-500` | `--n-0` | 无 | 每个视图最多 1 个（如"新建事件"） |
| 次 | `--n-0` | `--n-800` | `1px --n-300` | 常规次级操作 |
| 幽灵 | 透明 | `--n-700` | 无（hover 出 `--n-100` 底） | 工具栏、行内操作 |
| 危险 | 透明 | `--danger` | `1px --danger` | 删除、清空 |

尺寸：`sm 28px / md 36px / lg 44px`，左右内边距分别 `--sp-3 / --sp-4 / --sp-6`。
圆角 2px，字号 `--t-body`，字重 500。
**四态**：默认 / hover（主按钮转 `--a-600`，其余加 `--n-100` 底）/ active（`--a-700`）/ disabled（`--n-200` 底 + `--n-400` 字，`cursor: not-allowed`）。
图标按钮：正方形，尺寸与高度一致，图标 16px（sm）/ 20px（md/lg）。

### 6.2 输入框

- 高 36px，内边距 `0 --sp-3`，1px `--n-300` 描边，2px 圆角，`--t-body`。
- 聚焦：描边转 `--a-500` 2px，且 `outline: 2px solid var(--a-500); outline-offset: 2px`（**两者都要**，保证高对比模式下也可见）。
- 错误：描边 `--danger`，下方 `--t-sm` 红字说明（不弹 toast）。
- 多行（备注）：最小高 88px，可垂直 resize。

### 6.3 复选框（完成待办的核心控件）

- **18×18px 方块**，2px 圆角，1.5px `--n-400` 描边。
- hover：描边 `--a-500`。
- 选中：`--a-500` 填充 + 白色勾（1.5px 描边，SVG）。
- 点击热区 **44×44**（用 `::before` 扩大，视觉尺寸不变）。
- 完成后标题加 `line-through` + `--n-500`，**不做**变灰渐隐动画。

### 6.4 事件块 vs 待办块（全站最重要的视觉区分）

| | 日历事件 | 待办（有时间） |
|---|---|---|
| 底 | `--n-100`（灰） | 透明 |
| 描边 | 无（左侧 3px `--n-400` 色条） | **2px `--a-500`** |
| 文字 | `--n-800`，500 | `--n-800`，500 |
| 圆角 | 2px | 2px |
| 逾期 | — | 描边转 `--danger`，日期文字 `--danger` |
| 已完成 | — | 描边转 `--n-300`，文字 `--n-500` + 删除线 |

> 用"实心 vs 描边"区分来源，而不是用两种颜色。这是这套设计能不能立住的分水岭。

### 6.5 分段控件（视图切换）

- 高 28px，整体 1px `--n-200` 描边，2px 圆角，内部项无间隙。
- 选中项：`--a-500` 底 + 白字；未选中：`--n-0` 底 + `--n-600` 字。
- 项之间用 1px `--n-200` 竖线分隔。

### 6.6 Chip（标签）

- 高 22px，左右内边距 8px，`999px` 圆角，1px `--n-300` 描边，`--n-0` 底，`--t-sm`。
- 选中：`--a-100` 底 + `--a-500` 描边 + `--a-600` 字。
- 可删除 chip 带 12px × 图标，点击区 ≥24px。

### 6.7 列表行

```
┌──────────────────────────────────────────────────────────────┐
│ [□]  任务标题                          #标签  ●优先级  ⏱14:00 │  48px
│      └ 2/5 子任务                                  3 天前     │
└──────────────────────────────────────────────────────────────┘
       ↑ 44×44 热区      ↑ flex:1 截断        ↑ 右对齐固定宽 200px
```

- 行高 48px，左内边距 8px，右内边距 16px。
- hover：整行 `--n-100` 底（不是单元素）。
- 选中：`--a-100` 底 + 左侧 2px `--a-500` 竖条。
- 行之间**无**分隔线（靠留白分组），仅分组之间 1px 线。

### 6.8 四象限卡

```
┌─────────────────────────┐
│ 01 重要且紧急            │  ← 角标 01~04 用 --t-xs 全大写
│                         │
│ □ 交季度报告   今天 18:00│
│ □ 回复法务邮件           │
│                         │
│ 3 项 · 1 项逾期          │  ← 底部汇总行 --t-sm --n-500
└─────────────────────────┘
```

- 卡片 1px `--n-200` 描边，2px 圆角，内边距 `--sp-4`。
- 象限之间 gap `--sp-3`（12px）。
- 拖拽目标态：底 `--a-100`，描边 2px `--a-500`（虚线 **禁止**）。
- 每格独立滚动（`overflow-y: auto`，自定义 6px 滚动条）。

### 6.9 热力图

- 格子 **11×11px**，圆角 2px，gap 3px。
- 5 档：`--n-100`（0）/ `--n-200`（1~25%）/ `--n-400`（26~50%）/ `--a-200`（51~99%）/ `--a-500`（100%）。
- 7 行（周一~周日）× 12 列（12 周），月份标签在顶部 `--t-sm --n-500`。
- hover：格子加 1px `--n-800` 描边 + tooltip「11 月 18 日 · 已完成」。
- 补卡日：同色但叠加 45° 斜纹（`repeating-linear-gradient` 2px 间隔，透明度 0.25）。

### 6.10 状态四件套（每个视图都必须有）

| 状态 | 形态 |
|---|---|
| 空 | 居中（唯一允许居中的场景）：一张 32px 线性图标（`--n-300`）+ 一行 `--t-md` 说明 + 一个主按钮。文案示例：「还没有待办。按 N 新建一条。」 |
| 加载 | 骨架屏，**与实际布局同构**（同高同宽），底色 `--n-100`，无 shimmer 动画（静止即可，shimmer 属装饰） |
| 错误 | 左对齐：`--danger` 2px 左边框 + 标题「加载失败」+ 一行原因 + 「重试」次按钮 |
| 同步中 | 不占内容区。仅在顶栏右侧 8px 圆点脉冲（`--a-500`，1.2s，`ease-in-out`，只改透明度） |

### 6.11 Toast

- 固定在底部居中（桌面）/ 底部 Tab 上方（移动端），距边 16px。
- `--n-900` 底 + `--n-0` 字，2px 圆角，高 40px，内边距 `0 16px`。
- 带「撤销」操作时，操作文字 `--a-200`（在深底上要提亮，`--a-500` 在 `--n-900` 上对比不足）。
- 停留 5s（含撤销）/ 3s（无操作）。同一时刻最多 1 条，新的替换旧的。

### 6.12 抽屉

- 宽 380px，从右滑入 180ms，`--n-0` 底，左侧 1px `--n-200` 分隔线（唯一允许的分隔线形式）。
- 顶部：标题 `--t-md` + 关闭图标按钮 32px；下方 1px 通栏线。
- 内容区可滚动，底部固定操作条（48px，含「保存」「删除」）。
- 移动端：全屏 sheet，从底部滑入，顶部有 32×4px 拖拽指示条（`--n-300`）。

### 6.13 快速新增浮层

- 定位：视口上方 20% 处居中，宽 560px。
- 结构：单行输入（高 44px，无描边只有底边 1px）+ 下方一行快捷键提示 `--t-sm --n-500`（如「Enter 保存 · Tab 更多字段 · Esc 关闭」）。
- 展开态：追加 4 个字段（日期 / 清单 / 优先级 / 标签），每行高 40px，左标签固定 80px。
- **不做**：不做"新建成功"提示（浮层清空本身就是反馈）。

## 8. 动效

| Token | 时长 | 用途 |
|---|---|---|
| `--d-fast` | 120ms | hover、焦点、chip 选中 |
| `--d-base` | 180ms | 抽屉滑入、视图切换淡入 |
| `--d-slow` | 240ms | 仅用于快速新增浮层的出现 |

缓动：`--ease: cubic-bezier(0.2, 0, 0, 1)`。

**禁止**：弹跳（`cubic-bezier` 带过冲）、旋转加载器（改用脉冲点）、列表项逐条入场（stagger）、超过 240ms 的任何过渡。

**必须**支持 `@media (prefers-reduced-motion: reduce)` → 全部时长置 0.01ms。

## 9. 可访问性

| 项 | 规格 |
|---|---|
| 焦点环 | `2px solid var(--a-500)` + `outline-offset: 2px`。**禁止 `outline: none`**，任何组件都不例外 |

## 11. 这份规范里最容易走样的四条

1. **有人会加阴影"让卡片浮起来"** —— 一旦加，瑞士风格立刻变成普通 SaaS 后台。
2. **有人会用颜色区分待办与日历事件** —— 必须用实心/描边，用颜色就没救了。
3. **有人会把圆角调到 8px 以上"更现代"** —— 圆角是这套设计的性格，2px 是硬约束。
4. **有人会在列表项之间加分隔线** —— 线一多，网格感就变成表格感，留白才是分层手段。
